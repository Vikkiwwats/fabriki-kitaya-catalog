# Работа с каталогом

Основной источник проекта — этот репозиторий GitHub: `Vikkiwwats/fabriki-kitaya-catalog`, ветка `main`.

- Рабочие файлы сайта находятся в `docs/`. Каталог не требует сборки или сервера приложений.
- Перед правками получите актуальную ветку `main`. Сохраняйте изменения коммитом в этом репозитории. Не используйте отдельный проект Sites как источник и не публикуйте туда новые версии.
- Для GitHub Pages используются ветка `main` и папка `/docs`. После включения Pages изменения этой папки публикуются GitHub автоматически.
- Не меняйте фирменный стиль без запроса: официальный логотип, красный, тёмный и светлый цвета, TildaSans.
- Сохраняйте постоянные нейтральные артикулы товаров и коллекций. Исходные PDF, Excel, оригинальные артикулы, имена и контакты фабрик, QR-коды и внутреннюю таблицу соответствий нельзя добавлять ни в сайт, ни в репозиторий, ни в историю коммитов.
- Перед новым импортом проверьте занятые артикулы и номера коллекций во всех `docs/data/*.json`. Для нового исходника выделяйте свободный номер коллекции.
- Не подменяйте товар фотографией похожей модели и не генерируйте изображения товаров. Характеристики, цены, минимальную партию и наличие не выдумывайте.
- Все пути к изображениям, шрифтам, JSON и библиотеке PDF должны оставаться относительными: сайт работает внутри пути репозитория на GitHub Pages.
- Выбор посетителя сохраняется локально в браузере. Не обещайте синхронизацию между устройствами, личный кабинет, общую серверную базу или автоматическую отправку менеджеру: этих функций нет.
- «Протезы и бельё» — последний, отдельный раздел с нейтральной обложкой. Не показывайте его товары и фото в общем каталоге, общем поиске, обложках или рекомендациях других разделов. Фотографии открываются после явного нажатия «Показать товары раздела»; при выходе обложка возвращается.
- Праздничное оформление применяется к разделу «Новый год» и его карточкам, не меняя остальные разделы. Сохраняйте доступность интерфейса при отключённой анимации.
- На главной используется сезонное превью с переходом в новогодний раздел. `assets/newyear-campaign.jpg` — сгенерированный рекламный фон; текст размещён отдельным HTML-слоем. Не используйте его вместо реальных фотографий в товарных карточках.
- Проверки перед публикацией: `node --check docs/app.js` и `python scripts/validate_catalog.py`. Для второй проверки нужен Pillow.
- После правок поиска, категорий или рекомендаций запускайте `node scripts/check_catalog_visibility.js` и проверяйте отдельную обложку в браузере.
- После изменений поведения проверьте затронутый сценарий, включая подборку и PDF, если он менялся. Проверяйте загрузку изображений при публикации на GitHub Pages.
