# Фабрики Китая — каталог товаров

## [Открыть сайт-каталог ↗](https://vikkiwwats.github.io/fabriki-kitaya-catalog/)

Каталог опубликован на GitHub Pages и открыт для посетителей без регистрации.

Самостоятельный статический сайт: категории, поиск, тематические подборки, избранные товары, количество, комментарии и подготовка PDF для менеджера.

**Основной проект:** этот репозиторий GitHub, ветка `main`. Все файлы сайта находятся в `docs/`. Для работы каталога не нужны ChatGPT, Sites, внешняя база данных или платные API.

## Публикация на GitHub Pages

GitHub Pages включён: **Deploy from a branch → main → /docs**. Репозиторий открыт. Файлы сайта публикуются непосредственно из этого репозитория.

После изменения `docs/` в ветке `main` GitHub автоматически обновляет сайт. Статус публикации доступен в **Actions**, текущая ссылка — в **Settings → Pages**. Отдельный собственный workflow не нужен; `docs/.nojekyll` отключает обработку через Jekyll.

## Структура

- `docs/index.html`, `docs/styles.css`, `docs/app.js` — интерфейс каталога.
- `docs/data/products.json` — карточки с нейтральными артикулами и кодами коллекций.
- `docs/assets/products/` — обработанные фотографии товаров без исходных метаданных.
- `docs/assets/brand-logo.svg` и `brand-mark.svg` — официальный логотип.
- `docs/assets/fonts/` — локальные шрифты интерфейса и PDF.
- `docs/assets/vendor/` — jsPDF и лицензия.
- `scripts/validate_catalog.py` — проверка данных, изображений и отсутствия исходных документов в публикуемой папке.
- `AGENTS.md` — правила дальнейшей работы с репозиторием.

Исходные PDF и таблицы фабрик, названия и контакты поставщиков, оригинальные имена файлов и внутренний указатель соответствий не входят в репозиторий. Не добавляйте их ни в публичную папку, ни в историю проекта.

## Обновление товаров

Редактируйте `docs/data/products.json`, сохраняя существующие `id`. Новым позициям присваиваются нейтральные внутренние артикулы. `collection` и `collectionName` также должны быть нейтральными.

Не включайте названия поставщиков, оригинальные артикулы и имена файлов, контакты или QR-коды, позволяющие определить фабрику. Изображения сохраняйте в `docs/assets/products/`, очищайте от метаданных и проверяйте, что на них нет фабричных контактов или водяных знаков. Не заменяйте фотографию изображением похожей модели. Не выдумывайте цены, минимальную партию, наличие и характеристики: условия подтверждает менеджер.

## Подборки посетителей

Раздел «Новый год» имеет праздничную обложку, быстрые переходы по подразделам и тематическое оформление карточек.

«Протезы и бельё» находится в конце списка разделов, имеет нейтральную обложку и показывает фотографии только после нажатия «Показать товары раздела». Эти позиции исключены из общего каталога, общего поиска и рекомендаций других категорий. Это управление отображением, а не парольная защита: файлы открытого репозитория остаются публичными.

Выбор сохраняется на текущем устройстве в браузере. PDF предназначен для самостоятельной передачи менеджеру. JSON-файл подборки позволяет сохранить и восстановить выбор на другом устройстве или после смены адреса сайта. Личного кабинета, автоматической отправки сообщений и синхронизации между устройствами нет.

При переходе со старого адреса сохранённые в браузере подборки не переносятся автоматически: сначала сохраните JSON-подборку на старом сайте, затем восстановите её на новом.

## Проверка и локальный запуск

```sh
node --check docs/app.js
node scripts/check_catalog_visibility.js
python scripts/validate_catalog.py
python -m http.server 8000 --directory docs
```

Для проверки изображений в Python нужен Pillow. Открывайте каталог через HTTP-сервер: загрузка JSON может не работать при открытии `index.html` как локального файла.
