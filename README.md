# Фабрики Китая — каталог товаров

Каталог с категориями, поиском, тематическими подборками и выгрузкой выбранных товаров в PDF.

## Состав

- `dist/index.html`, `styles.css`, `app.js`: адаптивный интерфейс, подборка, сохранение и восстановление, PDF.
- `dist/data/products.json`: проверенные публичные карточки с постоянными артикулами и нейтральными кодами коллекций.
- `dist/assets/products`: очищенные изображения товаров с нейтральными именами файлов.
- `dist/assets/brand-logo.svg`: логотип с официального сайта компании.
- `dist/assets/vendor`: локальная библиотека jsPDF и лицензия.

Исходные каталоги, данные поставщиков и внутренний указатель соответствий не входят в этот проект. Не добавляйте их в репозиторий или публикуемую папку.

## Добавление товаров

Карточки добавляются после проверки исходника. Сохраняйте существующие `id`; новые позиции получают новые внутренние артикулы. Публичные `collection` и `collectionName` должны быть нейтральными. Не включайте названия поставщиков, оригинальные имена файлов, контакты, QR-коды и заводские коды, позволяющие определить поставщика.

Изображения должны находиться в `dist/assets/products`, быть очищенными и повторно сохранёнными без исходных метаданных. Не заменяйте фотографию на изображение похожей модели.

Цена, минимальная партия и характеристики, отсутствующие в исходных данных, не выдумываются. Условия подтверждает менеджер.

## Подборки

Выбор сохраняется на устройстве посетителя. PDF предназначен для передачи менеджеру. JSON-файл подборки позволяет восстановить доступные позиции на другом устройстве. Личного кабинета и автоматической отправки сообщений нет.

## Публикация

Публикуется содержимое `dist`. Исходный код может храниться в GitHub; рабочую коммерческую витрину следует размещать на хостинге, условия которого допускают её использование. Не переносите внутренние файлы в `dist`.

## Проверка

`node --check dist/app.js`

`python scripts/validate_catalog.py`
